# **더 게임 오브 더 래더The Game of Ladder** #
  
##### [기획서 Notion](https://app.notion.com/p/2D-40cc601cdc8281caa0b7e30e6bd52b1d#d0da9375914a4c5b8d9180fb4769ff67) #####
  
  
###### **1. 게임 개요** #####
- 장르: 2D 정밀 조작 플랫포머(항아리류)
- 주제: 계급 상승과 추락
- 핵심 경험: 사다리 하나를 운반해 각도와 길이를 조절하고, 사다리 하나를 운반해 각도와 길이를 조절하고, 설치·등반·회수하며 재사용하고, 설치 실수와 추락에서 복구해 다시 도전하는 경험
- 주요 참고: 'Jump King'의 수직 상승, 'Getting Over It' / 'Get to Work' 계열의 숙련·추락 구조
- 제작 목표: 2주 내 완성 가능한 범위
  
- 한 줄 콘셉트: 수평 발판으로 이루어진 수직 공간에서 길이 조절이 가능한 사다리 하나를 반복해서 설치·회수하며 계급을 상승시키는 항아리류 게임
  
  
##### **2. 핵심 규칙** #####
- 모든 일반 지형은 수평 구조로 구성한다.
- 플레이어는 점프를 사용할 수 없다. 오로지 사다리를 통해 고도를 올릴 수 있다.
- 사용 가능한 사다리는 항상 하나이다.
- 사다리는 상층 플랫폼의 모서리에 정확히 설치해야 정상적인 등반이 가능하다.
- 불안정한 설치도 허용하되, 실제 등반 도중 기하학적 판정에 따라 미끄러진다. 같은 설치 위치·각도·길이에서는 같은 결과가 발생한다.
- 미끄러짐이 시작되면 일시적으로 조작권을 잃고 아래 발판까지 추락할 수 있다.
- 플랫폼의 특정 구간에 사다리 재발급 거점을 둔다.
- 플레이어는 A / D로 이동, W는 상태 전환·상호작용 버튼이다. 점프 기능은 없다.
- 거점 주변에서 W를 누르면 사다리를 얻고, 기존 사다리는 사라진다.
- 거점의 사다리 재발급소 범위에서는 재발급이 회수보다 우선 실행된다.
- 계급 상승은 구간 진입 시의 팻말과 안내 멘트로 전달한다.
  
  
##### **3. 플레이어 조작** #####
**평시 이동**
-A / D: 좌 / 우 이동
- W: 사다리 회수('사다리 운반' 모드 진입) 또는 사다리 재발급
  
**사다리 운반**
- A / D: 사다리를 든 채 좌 / 우 이동
- W: '사다리 각도 조절' 모드 진입
  
**사다리 각도 조절**
- A / D: 캐릭터의 발 위치를 축으로 사다리 회전
- W: '사다리 길이 조절' 모드 진입
  
**사다리 길이 조절**
- A / D: 플레이어가 바라보는 방향에 맞게 사다리 수축 또는 연장
- W: 짧게 누르면 발판 위에서 설치 후 평시 이동. 길게 눌렀다 떼면 각도 조절로 복귀. 공중 설치 불가
  
**설치 후 등반**
- A / D: 사다리의 기울기 방향으로 상승, 반대 방향으로 하강
- W: 사다리 회수 가능. 등반 도중 회수해 지지를 잃으면 사다리를 든 채 낙하
  
**일반 낙하**
- A / D: 평시 이동과 운반 상태에서는 수평 입력 가능. 운반 중에는 사다리도 함께 이동
- W: 사다리 접근·보유 상태에 따른 회수·모드 전환 가능. 공중 설치는 불가
  
**미끄러짐에 따른 조작 제한**
- A / D: 조작 가능. 단, 조작 민감도는 추락 방향과 반대로 조작 시 관성에 따른 미끄러짐을 조금 감소시키는 정도만 가능
- W: 조작 불가

**기본 조작 순서**
사다리 접근 → W(회수) → A/D(운반) → W(각도 조절) → A/D(회전) → W(길이 조절) → A/D(수축·연장) → W(설치) → A/D(등반) → 상층 착지 → W(회수).
  
  
##### **4. 구현 원칙** #####
- 상태를 평시 이동 / 운반 / 각도 조절 / 길이 조절 / 등반 / 미끄러짐 등으로 구분한다.
- 사다리는 완전한 강체 물리 대신 기하학적 접촉 계산과 상태 머신으로 처리한다.
- P05(프로토타입)의 월드 좌표는 위쪽이 +Y이므로 끝점을 다음과 같이 계산한다.  
    끝점 x = 시작점 x + L × cos(θ)  
    끝점 y = 시작점 y + L × sin(θ)  
- 화면 좌표로 그릴 때는 Y 방향을 뒤집는다. 화면에서 아래쪽을 +Y로 사용하는 표현에서는 기존의 y − L × sin(θ)와 같은 방향이다.
- 설치 판정과 실제 미끄러짐 시점을 구분한다. 정확한 설치는 같은 조건에서 일관되게 성공해야 한다.
- 화면에 그리는 사다리와 판정에 사용하는 사다리는 같은 길이·각도를 사용한다.
- 회수·재발급 시 이전 설치를 해제하고 사다리 하나를 보유 상태로 옮겨 중복을 방지한다.
